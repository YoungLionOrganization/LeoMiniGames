# Contributing to LeoMiniGames

LeoMiniGames is source-available, not open source.

## Contribution license

Do not submit a contribution unless you have the right to submit it.

External contributions may be accepted only after the contributor satisfies the
current `CONTRIBUTOR_LICENSE_AGREEMENT.md` process designated by the project.

A pull request does not grant the contributor authority to distribute an
alternative LeoMiniGames build or designate an Official Release.

## Contribution forks

Public forks are permitted only within the contribution-fork exception in the
main `LICENSE`.

Do not publish releases, APKs, installers, AppImages, DMGs, binaries, or package
registry artifacts from a contribution fork.

## Third-party code

Do not copy third-party code into the project without documenting:
- source;
- copyright holder;
- exact license;
- required notices;
- compatibility with the project's distribution model.

GPL-only code must not be incorporated into project-owned host code intended for
the source-available license unless a separate legal basis permits the exact
distribution.

## SDK boundary

Only files expressly licensed under
`LicenseRef-YoungLion-LMG-SDK-1.0`
are Publisher-facing SDK/template material.

Do not expose internal implementation as public SDK accidentally.

## Security/trust

Manifest fields are untrusted input. Official/Verified/Native-L3 and privileged
capabilities must remain backend-authoritative.
