# LeoMiniGames v0.5.1

- Qt Multimedia is now required; builds no longer silently ship with sound disabled.
- Added `Audio.playUrl()` and `Audio.preload()` for trusted RCC-local mod sound effects.
- Added catalog `icon_url` role and remote custom mod icons with fallback.
- Android versionName/versionCode updated to 0.5.1 / 501.
- Mod SDK v1.1 documents self-contained QML, local icons and local sounds.
- Android deployment note: deploy the `LeoMiniGames` executable target, never a static built-in plugin target.
