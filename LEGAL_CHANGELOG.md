# LeoMiniGames Legal Changelog

## 19 September 2026 — Source-available transition

Planned current host license:
`LicenseRef-LMG-SAPEL-1.0`

### Architecture changes

- Replace GPL-3.0-or-later as the current host license.
- Remove the need for a GPL section 7 Plugin/Mod Exception for new
  source-available host editions.
- Introduce a dedicated SDK/template license.
- Introduce a Publisher Package proprietary license.
- Require versioned Publisher Terms acceptance.
- Add Native/L3 security addendum.
- Preserve third-party LGPL/other license rights.
- Mark official F-Droid main-repository targeting incompatible with the new host
  licensing model.
- Add CLA rights sufficient for future project relicensing.

### Historical grants

Earlier public GPL-identified copies are not retroactively revoked.
