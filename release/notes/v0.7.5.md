# LeoMiniGames v0.7.5

Development notes. The [v0.7.4 release](https://github.com/YoungLionOrganization/LeoMiniGames/releases/tag/v0.7.4) remains available.

## Games and themes

- Reaction Tap fits its main touch area and state text on short landscape screens. The waiting instructions work with any theme accent color.
- Imported host QML singletons in external games can resolve the same game-scoped theme services as the entry component.
- Legacy theme palettes and radii are imported from JSON. Canonical themes retain the data-only format.
- Theme duration tokens retain their millisecond values, and progress controls retain their intended dimensions.

## Linux packages and validation

- Online desktop kits include Qt image formats. Packaged runtime checks decode PNG, JPEG, SVG and WebP and exercise the required QML imports.
- Ubuntu portable packaging omits the optional Qt TIFF codec when its legacy TIFF library is unavailable.
- Debian packages declare their SVG, WebP, QML and font runtime dependencies. Native package tests install the package in a fresh distro environment.
- Linux package audio probes play an effect and a music clip and check the resulting PulseAudio monitor recording.

See the [runtime investigation](../../docs/releases/V074_LINUX_RUNTIME.md) for the earlier source and evidence. The game API remains 0.7, including legacy RCC compatibility. The release kit remains Qt 6.10.2. The candidate requires exact-source CI and package verification before publication.
