# LeoMiniGames v0.7.1

v0.7.1 is a servicing release focused on reliable delivery and updates without changing the game/mod compatibility contract.

## Release and update infrastructure

- Adds a deterministic `release-assets` aggregation step so public GitHub Release files can be uploaded as one validated set.
- Adds a manual, guarded `Publish Release` workflow with exact-commit CI/build checks, duplicate release protection, draft-first publishing and asset verification.
- Fixes draft publication retries by tracking the numeric GitHub release ID; partial drafts are recovered and their asset set is rebuilt safely instead of failing on the published-tag lookup.
- Adds canonical release metadata and a public asset allowlist.
- Adds Qt Installer Framework hybrid installers and GitHub-hosted maintenance repositories for Windows x86_64 and ARM64.
- Adds a Maintenance shortcut for update, repair/modify and uninstall operations.

## Application updates

- Routes update discovery, release metadata, package downloads and Windows QtIFW repository access through `leominigames.younglion.xyz`; GitHub is now a replaceable backend upstream rather than an application dependency.
- Adds a host-level GitHub update service.
- Supports Stable and Preview update channels with SemVer-aware prerelease ordering.
- Installed Windows builds hand update execution to the QtIFW Maintenance Tool.
- Portable/other builds can open the matching public GitHub Release asset or release page.
- Remote metadata is size-bounded and accepted only from HTTPS GitHub endpoints.

## Compatibility

- No new game/mod API is required by v0.7.1.
- Existing v0.5/v0.6/v0.7 package compatibility remains a release requirement.
- Save Transfer and the `.lmgsave` portable format remain planned for the v0.8.0 development line.
