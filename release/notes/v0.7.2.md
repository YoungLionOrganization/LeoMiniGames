# LeoMiniGames v0.7.2

v0.7.2 improves installer servicing, data safety and release delivery while preserving the v0.5/v0.6/v0.7 RCC game and mod compatibility contract.

## Fixes

- Windows Setup recognizes an existing installation and hands Update, Modify and Uninstall to its Maintenance Tool before the occupied directory check. The application component is selected by default, the “You are installing” summary is populated, and optional shortcut controls are guarded when a page has not been created.
- Developer Lab stores an API key in the operating system credential store only after opt-in. Restored keys are verified again; logging out cancels pending responses. Failed keychain writes do not fall back to plaintext.
- Creating a save slot no longer overwrites an existing slot. Nested JavaScript snapshot values are normalized before serialization.
- Catalog, update and developer responses have byte and time limits; malformed catalog URLs are rejected.
- Android packages require signing credentials and include checked OpenSSL libraries per ABI. The build validates packaged native libraries and 16 KiB alignment.
- The backend companion tightens HTTPS and proxy handling, limits upstream and request sizes, checks archives and uses short-lived developer sessions. Deploy the companion separately with its migration and installation checks.

## Updates and downloads

Windows Setup installations use the bundled Maintenance Tool and a Windows QtIFW repository for their CPU variant. Other packages receive update notices and backend download links; install the new package using the platform's normal procedure. The `updates` branch stores QtIFW payloads for Windows only and does not contain every platform's download assets.

The public release has 27 assets: source ZIP; Windows x86_64, x86_64 AVX2 and ARM64 portable ZIPs and Setup EXEs; Linux portable, AppImage and native packages; macOS ZIPs and DMGs; and Android APKs. AABs and unsigned Apple test bundles remain internal workflow artifacts.

## Verification and limits

CI and Build Release Artifacts validated the 27-asset candidate. The Windows installer flow was additionally confirmed by a user after the previous installer fixes. Hardware coverage, Android installation, Apple signing/notarization and the separately deployed backend require their own environment checks; a successful build does not establish those results.

No new game/mod API is required. Save Transfer and the portable `.lmgsave` format remain planned for v0.8.0.
