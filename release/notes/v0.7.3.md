# LeoMiniGames v0.7.3

This patch repairs the Android OpenSSL library dependency, explicitly extracts native TLS plugins and checks every packaged ABI's dependency closure and compiled manifest. Emulator evidence must include a certificate-validated HTTPS catalog request. Windows portable and installer payloads include the matching MSVC runtime DLLs.

Save files that fail loading are protected from automatic overwrite. Repeated unchanged saves preserve recovery backups. Session shutdown runs through one guarded lifecycle sequence, and external game migrations use the game's own JavaScript engine. Input handling uses native Qt key events, and builtin timers suspend while backgrounded.

Backup recovery validates migrations before changing files, and missing primaries with surviving backups remain protected until successfully loaded. Malformed catalog rows preserve the previous list. Resource filenames containing URL delimiters load correctly, and keyboard layout changes no longer leave native actions stuck.

Explicit save deletion handles protected slots and restores staged backups on failure. Invalid numeric service values no longer unlock achievements, accelerate timing or hold input; statistics avoid overflow and preserve full stores. Reentrant game transitions discard stale lifecycle/open notifications and retain replacement sessions.

Cancelled external QML loads cannot publish a late ready state or replace a newer session. Missing required root properties report a load error and retire the failed component.

Update actions require a newer validated version. Linux desktop updates open the release page for distribution and package-format selection instead of using a generic recommended binary.

Package updates preserve installed runtime metadata, reject incompatible candidates and restore the previous package if the installed index cannot be committed. Running game packages cannot be replaced or removed. Theme downloads verify package identity and version against the catalog.

Linux packages now include Debian DEBs, Fedora RPMs, an Arch pacman package, KDE Flatpak bundles and a portable user Setup.run installer alongside AppImage/tarballs. Automated Linux tests install, launch all six games, reinstall and uninstall, retaining user data. Android AVD creation is checked before launching the emulator; ARM64 CRT deployment filters files by PE architecture.

Failed Linux user-installer upgrades restore the previous payload and integration files. If rollback also fails, recovery files are retained and their location is reported.

The installation guide covers package selection, Arch/Flatpak, upgrading and removal, and is included in desktop payloads. Windows artifact jobs exercise portable/Setup launch and Maintenance Tool servicing on disposable runners, including an older-metadata upgrade fixture and optional-component modification. A separate GitHub lane checks Qt 6.12 desktop compatibility; the release kit remains Qt 6.10.2, and HarmonyOS is preparation for a later version.

Windows online upgrades register the installed component version instead of retaining the original Setup version. macOS packages are assembled before ad-hoc signing, and signature integrity is verified in both ZIP and DMG payloads; Developer ID signing and notarization remain separate.

Audio error handlers can stop or replace music safely. A newer nested music request retains ownership of playback instead of being overwritten by a retired request.

Interrupted save migrations and snapshot callbacks cannot populate another game's memory. Retired save notifications preserve the replacement session's pending changes.

Release validation checks the exact 39 asset names, archive contents, native dependency closure and remote sizes/digests. API compatibility remains 0.7; all six built-in games use native lifecycle hooks and atomic state persistence; boards, hands, flags and active time resume, while Reaction Tap restarts active timing rounds. Platform launch and installer QA must be completed against fresh v0.7.3 artifacts before publication. The historical backend companion has not been deployed by this patch.
