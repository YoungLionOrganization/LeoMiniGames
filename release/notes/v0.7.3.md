# LeoMiniGames v0.7.3

This patch repairs the Android OpenSSL library dependency, explicitly extracts native TLS plugins and checks every packaged ABI's dependency closure and compiled manifest. Emulator evidence must include a certificate-validated HTTPS catalog request. Windows portable and installer payloads include the matching MSVC runtime DLLs.

Save files that fail loading are protected from automatic overwrite. Repeated unchanged saves preserve recovery backups. Session shutdown runs through one guarded lifecycle sequence, and external game migrations use the game's own JavaScript engine. Input handling uses native Qt key events, and builtin timers suspend while backgrounded.

Package updates preserve installed runtime metadata, reject incompatible candidates and restore the previous package if the installed index cannot be committed. Running game packages cannot be replaced or removed. Theme downloads verify package identity and version against the catalog.

Linux packages now include Debian DEBs, Fedora RPMs, an Arch pacman package, KDE Flatpak bundles and a portable user Setup.run installer alongside AppImage/tarballs. Automated Linux tests install, launch all six games, reinstall and uninstall, retaining user data. Android AVD creation is checked before launching the emulator; ARM64 CRT deployment filters files by PE architecture.

Release validation checks the exact 39 asset names, archive contents, native dependency closure and remote sizes/digests. API compatibility remains 0.7; all six built-in games use native lifecycle hooks and atomic state persistence; boards, hands, flags and active time resume, while Reaction Tap restarts active timing rounds. Platform launch and installer QA must be completed against fresh v0.7.3 artifacts before publication. The historical backend companion has not been deployed by this patch.
