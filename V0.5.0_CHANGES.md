# LeoMiniGames v0.5.0

## Fixed
- Restored the original LeoMiniGames lion/controller branding and applied a mild contrast/sharpness cleanup instead of replacing the identity.
- Android launcher icons now use density-specific `mipmap-*` resources generated from the restored logo.
- In-app icons no longer depend on emoji/Unicode or external PNG loading: they are drawn by QML Canvas, so the same icons render on Windows and Android.
- Minesweeper pointer handling now uses Qt 6 `TapHandler`: short tap reveals, long press flags, right click flags, and Flag mode remains available.
- Android Back is consumed by the Qt event filter and mapped to the same StackView navigation as the in-app Back button.
- The mod SDK example no longer imports the application-private `LeoMiniGames` QML module. This removes the qmlimportscanner warning while keeping the main app as a proper compiled Qt QML module.
- Android HTTPS/mod catalog keeps the OpenSSL 3 deployment integration.
- Mod install can use a direct `download_url` from Hub v1.0.2+, avoiding the old download-ticket 500 failure path; the legacy ticket route remains as fallback.
- Android manifest explicitly identifies the application as a game (`appCategory=game`, `isGame=true`, `CATEGORY_GAME`).
- Version is locked consistently to `0.5.0`; Android `versionCode` is `500` in both CMake deployment settings and the custom manifest.
- Android compile/target SDK is pinned to API 36 and Build Tools 36.0.0.

## Languages
English, Azerbaijani, Turkish plus Russian, German, French, Spanish, Portuguese, Italian, Dutch, Polish, Ukrainian, Arabic, Persian, Japanese, Korean, Simplified Chinese, Traditional Chinese, Hindi, Indonesian, Vietnamese, Swedish, and Greek are selectable. Missing individual phrases fall back to English.

## Backend hotfix
The project ZIP contains `deployment/backend-hotfix-v1.0.2`. Upload its updated `app/ApiController.php` and `app/R2Signer.php` to the existing Hub backend without overwriting your real `config/config.php`. The download-ticket route now falls back to a short-lived presigned R2 GET URL when no public R2 domain is configured, and download-counter failures are non-fatal.

## Android build note
After upgrading from v0.4.x, delete the old Android build directory once and reconfigure. Android Gradle/Manifest output is generated into the build directory, so reusing the old cache can preserve stale `versionName` and resources.
