## Qt is not an automatic blocker

LeoMiniGames is a Qt 6 Android application. F-Droid cannot use a proprietary/prebuilt Qt Online Installer SDK as an opaque build dependency, but that does **not** mean Qt 6 applications are inherently unacceptable. Current fdroiddata contains Qt 6 applications that use the historically named `Qt5` srclib and compile Qt from source; GCompris currently demonstrates `Qt5@v6.10.1` with NDK r27c.

For LeoMiniGames, the final fdroiddata merge request therefore needs a tested, minimized Qt source build that provides at least the modules required by the host (`qtbase`, `qtdeclarative`, `qtsvg`; `qtmultimedia` if audio is retained in the F-Droid build). The repository scaffold references `Qt5@v6.10.1` as the current precedent, but it intentionally does not pretend that the complete source-build stanza has already been validated for this project.

## Build policy

`LEOMINIGAMES_FDROID=ON` is the F-Droid build switch. It must remain free of proprietary SDKs, trackers, advertising libraries, downloaded binary plugins and network-fetched code during build. `tools/audit_prebuilt_binaries.py` and `tools/validate_v070.py` are run before the clean Android build.

`tools/fdroid_clean_build.sh` does not download Qt. It requires a FOSS-built Qt Android `qt-cmake`, Android SDK and NDK supplied by the fdroidserver recipe. That separation is intentional: upstream does not smuggle prebuilt Qt binaries into the source repository.

## Metadata and graphics

Fastlane metadata under `fastlane/metadata/android/` remains the upstream source for title, descriptions, changelog and graphics. The 512px application icon is present. Real phone screenshots are still required before submission; mock screenshots are not accepted as a substitute and are intentionally not generated by validators.

## Submission gates

Before opening the fdroiddata merge request, all of the following must be true:

1. Commit the final source/build recipe and record its exact 40-character SHA.
2. Replace `FULL_COMMIT_SHA` in `fdroid/metadata/xyz.younglion.leominigames.yml.example`.
3. Complete and test the Qt 6 source-build stanza in an actual fdroidserver environment.
4. Confirm the produced unsigned APK has application ID `xyz.younglion.leominigames`, versionName `0.7.0`, versionCode `700` and contains no forbidden prebuilt/non-free dependencies.
5. Add real screenshots to Fastlane metadata.
6. Run the repository validators and `fdroid lint`/`fdroid build` in the fdroiddata workflow.

Until gates 2–6 have been executed, the repository is **F-Droid prepared**, not falsely labelled “accepted” or “reproducibly built by F-Droid”.
